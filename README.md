# SpeakBloom - Speech & Language Therapy HTML5 Template

SpeakBloom is a multipurpose, modern, responsive HTML5 & TailwindCSS/Bootstrap web template designed specifically for speech-language pathology clinics, pediatric therapy centers, adult communication rehab facilities, and healthcare practitioners.

## ✨ Features
- **Responsive & Mobile-First Design**: Optimized for smartphones, tablets, and desktops.
- **Dark & Light Mode**: Built-in instant theme switcher with persistent local storage.
- **RTL Support**: Built-in Right-to-Left language layout switcher.
- **12 Dedicated Service Pages**: Comprehensive individual service landing pages with FAQs, therapist highlights, and booking CTAs.
- **Milestone & Diagnostic Pages**: Milestone tracking and age-based speech guides.
- **Clean Semantic Code**: Production-ready, accessible, SEO-friendly HTML5 and modern CSS/JS.
- **No Dependencies Required**: Works right out of the box by opening index.html in any modern web browser.
